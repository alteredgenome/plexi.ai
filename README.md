# Plexi Web & Installer Site

This repository contains the landing page, documentation, and installation scripts for **Plexi** (`plexi.ai` / `plexi.fyi`).

## Files
- `index.html`: Modern landing page hosted on GitHub Pages (`alteredgenome.github.io/plexi.ai` / `plexi.fyi`).
- `install.sh`: Single-line automated installer for Linux/macOS.

## Usage
To install Plexi:
```bash
curl -fsSL https://plexi.fyi/install.sh | bash
```
